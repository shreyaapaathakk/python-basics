# Virtual Environment

## Overview

A virtual environment is an isolated Python environment that allows each project to have its own Python interpreter and installed packages.

Using virtual environments helps avoid dependency conflicts between projects and makes applications easier to share and deploy.

---

## Topics Covered

- What is a virtual environment?
- Why use virtual environments?
- Creating a virtual environment
- Activating and deactivating environments
- Installing packages with `pip`
- Using `requirements.txt`
