# Advanced Object-Oriented Programming

This module builds upon the concepts learned in the previous OOP chapter.

Here, you'll learn features that are frequently used in professional Python development.

---

## Learning Objectives

After completing this module, you will be able to:

- Use class methods
- Use static methods
- Create properties
- Understand magic (dunder) methods
- Work with multiple inheritance
- Override inherited methods
- Use the `super()` function
- Overload operators
