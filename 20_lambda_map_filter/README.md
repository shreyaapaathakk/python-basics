# Lambda, Map, Filter & Reduce

## Overview

Python provides several built-in tools that make working with collections easier and more concise.

This module introduces **lambda functions**, `map()`, `filter()`, and `reduce()` to perform common operations in a functional programming style.

---

## Topics Covered

- Lambda functions
- map()
- filter()
- reduce()
- Sorting using lambda
- Functional programming basics

---

## Learning Objectives

After completing this module, you will be able to:

- Write anonymous functions using `lambda`.
- Transform data using `map()`.
- Select data using `filter()`.
- Combine values using `reduce()`.
- Sort lists using custom keys.
