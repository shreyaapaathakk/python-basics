# Decorators

## Overview

Decorators are one of Python's most powerful features.

A decorator allows you to modify or extend the behavior of a function **without changing its original source code**.

Decorators are commonly used for:

- Logging
- Authentication
- Timing functions
- Validation
- Caching
- Access control
