# Object-Oriented Programming (OOP)

Object-Oriented Programming (OOP) is a programming paradigm that organizes code into **objects**.

An object contains:

- Data (attributes)
- Behavior (methods)

Python supports OOP, making it easier to build reusable, scalable, and organized programs.

---

## Learning Objectives

After completing this module, you will be able to:

- Understand classes and objects
- Create your own classes
- Use constructors
- Work with attributes and methods
- Apply inheritance
- Understand polymorphism
- Use encapsulation
- Learn the basics of abstraction
- Build a small object-oriented project
