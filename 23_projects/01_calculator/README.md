# Calculator

## Overview

The **Calculator** project is the first project in the **Python Basics** repository.

It is a menu-driven console application that performs common arithmetic operations on two numbers. The project reinforces the concepts learned throughout the beginner modules, including variables, operators, functions, loops, conditional statements, exception handling, and user input.

Instead of exiting after one calculation, the application allows users to perform multiple calculations until they choose to quit.

---

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Floor Division
* Modulus
* Exponentiation
* User-friendly menu
* Input validation
* Division-by-zero handling
* Perform multiple calculations without restarting the program
