# To-Do List

A beginner-friendly To-Do List application built with Python. This project allows users to manage daily tasks through a simple menu-driven interface. It demonstrates how to use lists, dictionaries, functions, loops, and exception handling to build a practical console application.

---

## Overview

A To-Do List is one of the most popular beginner Python projects because it combines multiple programming concepts into a useful real-world application.

With this application, users can:

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Exit the application

This project emphasizes clean code, modular programming, and user-friendly interaction.

## How to Run

1. Open a terminal.
2. Navigate to the project folder.

```bash
cd 05_todo_list
```

3. Run the program.

```bash
python main.py
```
