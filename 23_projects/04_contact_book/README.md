# Contact Book

A beginner-friendly Contact Book application built with Python. This project demonstrates how to store, manage, search, and update contacts using lists and dictionaries. It is a menu-driven console application that emphasizes clean code, modular programming, and proper user input validation.

---

## Overview

Managing contacts is a common real-world task. This project allows users to create and maintain a simple contact list directly from the terminal.

Users can:

- Add new contacts
- View all contacts
- Search for contacts
- Update existing contacts
- Delete contacts
- Exit the application

The program is designed to help beginners practice working with Python functions, loops, dictionaries, lists, and exception handling.

---
