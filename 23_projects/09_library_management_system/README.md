# Library Management System

A beginner-friendly Library Management System built with Python. This project demonstrates how to manage a collection of books using a menu-driven console application. It allows users to add, view, search, issue, return, and delete books while practicing important Python concepts such as lists, dictionaries, functions, loops, conditionals, and exception handling.

---

## Overview

Libraries maintain large collections of books and keep track of their availability. This project simulates a simple library management system where each book has a unique ID, title, author, and availability status.

Users can:

- Add new books
- View all books
- Search for books
- Issue books
- Return books
- Delete books
- Exit the application

The project focuses on writing clean, modular, and beginner-friendly Python code.
