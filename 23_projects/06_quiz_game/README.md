# Quiz Game

A beginner-friendly Quiz Game built with Python. This project demonstrates how to create an interactive multiple-choice quiz using lists, dictionaries, functions, loops, and conditional statements. It is a menu-driven console application designed to help beginners practice fundamental Python concepts while building a fun real-world project.

---

## Overview

Quiz applications are excellent beginner projects because they combine user interaction, data structures, loops, and decision-making.

This application allows users to:

- Start a quiz
- Answer multiple-choice questions
- View their final score
- See the correct answers
- Play the quiz again
- Exit the application

The project focuses on writing clean, modular, and beginner-friendly Python code.
