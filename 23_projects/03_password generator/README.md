# Password Generator

## Overview

The **Password Generator** is a console-based Python application that creates strong, random passwords based on the user's preferences.

The user can specify the password length and choose whether to include uppercase letters, lowercase letters, numbers, and special characters. The program then generates a secure password using Python's built-in `random` module.

This project helps reinforce concepts such as functions, loops, strings, lists, user input, conditional statements, and input validation.

---

## Features

* Generate passwords of any valid length
* Include uppercase letters
* Include lowercase letters
* Include digits
* Include special characters
* Input validation
* Generate multiple passwords without restarting
* User-friendly console interface
