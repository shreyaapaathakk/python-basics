# Expense Tracker

A beginner-friendly Expense Tracker built with Python. This project helps users record and manage their daily expenses through a simple menu-driven console application. It demonstrates the use of lists, dictionaries, functions, loops, conditionals, and basic calculations while reinforcing good programming practices.

---

## Overview

Managing personal expenses is a practical real-world application of programming. This project allows users to keep track of their spending by recording expense details and viewing summaries.

Users can:

- Add new expenses
- View all expenses
- Calculate total expenses
- Search expenses by category
- Delete an expense
- Exit the application

This project focuses on writing clean, modular, and beginner-friendly Python code.

1. Open a terminal.
2. Navigate to the project folder.

```bash

```

3. Run the application.

```bash

```
