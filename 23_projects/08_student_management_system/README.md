# Student Management System

A beginner-friendly Student Management System built with Python. This project allows users to manage student records through a simple menu-driven console application. It demonstrates the use of lists, dictionaries, functions, loops, conditionals, and exception handling while following clean coding practices.

---

## Overview

Managing student information is a common real-world programming task. This project helps beginners learn how to store, retrieve, update, and delete records using Python data structures.

Users can:

- Add new students
- View all student records
- Search for a student
- Update student information
- Delete a student record
- Exit the application

The project emphasizes modular programming, input validation, and readable code.
