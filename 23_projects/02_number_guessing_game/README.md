# Number Guessing Game

## Overview

The **Number Guessing Game** is a fun console-based Python project where the computer randomly selects a number within a given range, and the player tries to guess it.

After each guess, the program provides helpful hints indicating whether the guess is too high or too low. The game continues until the correct number is guessed.

This project strengthens your understanding of loops, conditional statements, user input, random number generation, and exception handling.

---

## Features

* Randomly generates a secret number
* User-friendly menu
* Input validation
* Helpful hints after each guess
* Tracks the number of attempts
* Option to play multiple rounds
* Congratulates the player upon winning
