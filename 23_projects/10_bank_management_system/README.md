# Bank Management System

A beginner-friendly Bank Management System built with Python. This project demonstrates how to create a simple banking application using a menu-driven console interface. It allows users to create an account, deposit money, withdraw money, check their balance, view transaction history, and manage their account while practicing fundamental Python programming concepts.

---

## Overview

Banking systems involve storing and managing customer information, handling transactions, validating user input, and maintaining account balances. This project combines many Python concepts into a practical real-world application.

Users can:

- Create a bank account
- View account details
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Exit the application

The project emphasizes clean coding practices, modular programming, and beginner-friendly design.

